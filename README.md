# CountriesDropDown

Open `country-states/index.html` in a browser to try the dependent country and
state fields. The demo loads its country and region data from the bundled
`country-states/js/country-states.js` file.

- India is selected when the page opens.
- Selecting a country with listed regions shows a state dropdown.
- Selecting a country without listed regions lets you type a region name.
- Returning to **Select country** disables the state field until you choose a country.
